# Flavour Bites USA Flagship

Premium Next.js storefront foundation for `flavourbites.us`.

## Run locally

```bash
npm install
npm run dev
```

## Production

Deploy to Vercel and connect the Git repository.

## Required before commercial launch

- Replace packaging design boards with final product photography where appropriate.
- Connect checkout to the real One Stop Halal or selected commerce provider.
- Verify final prices, stock, ingredients, allergens, nutrition facts and directions.
- Add final privacy, terms, shipping, returns and accessibility pages.
- Confirm the written U.S. distribution and fulfillment arrangement.
